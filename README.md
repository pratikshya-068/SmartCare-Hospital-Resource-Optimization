# SmartCare – Hospital Resource Optimization

## Project Overview
SmartCare is a web-based Hospital Resource Optimization System developed using Python and Django. It helps manage patient records and hospital bed availability through a simple dashboard.

## Features
- Patient Registration
- Patient Records Management
- Search, Edit and Delete Patient Records
- Hospital Bed Management
- Available and Occupied Bed Tracking
- Dashboard with Patient and Bed Statistics
- AI-Based Patient Flow Estimation

## Technologies Used
- Frontend: HTML, CSS, JavaScript, Bootstrap
- Backend: Python, Django
- Database: MySQL
- Data Analysis: Pandas
- Machine Learning: Scikit-learn
- Tools: VS Code, MySQL Workbench, Git and GitHub

## Installation and Setup
1. Clone the repository.
2. Open the project folder in VS Code.
3. Create and activate a virtual environment.
4. Install the required packages.
5. Configure MySQL database settings.
